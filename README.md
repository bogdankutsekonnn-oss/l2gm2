# L2GM2 - MVP 

MVP сервиса для анонсов серверов Lineage 2, созданный на Nuxt 3.

## 🎯 Основные возможности

- **Анонсы серверов** - двухколоночный список серверов с категоризацией по датам
- **SEO-страницы** - автоматическая генерация страниц для каждого фильтра (хроники, рейты, комбинации)
- **Фильтрация** - правая панель с фильтрами по хроникам и рейтам
- **Автогенерация** - при добавлении новых данных в JSON файлы автоматически создаются новые SEO-страницы
- **SSR** - все страницы рендерятся на сервере для лучшего SEO

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для production

```bash
npm run build
```

### Генерация статических страниц

```bash
npm run generate
```

### Проверка сборки перед деплоем

```bash
npm run check:build
```

Гейт `scripts/check-build.mjs` не даёт уехать на прод странице ошибки под
адресом реальной статьи (так 13 адресов попали в индекс с заголовком
«Страница не найдена»), пустому `<title>`, битой внутренней ссылке и карте
сайта, обещающей несобранные страницы. В деплое запускается автоматически —
между `nuxt generate` и заливкой по FTP.

После заливки живой сайт обходит `scripts/check-live.mjs` (все собранные
адреса + всё из живого `sitemap.xml`). Его можно запустить и руками:

```bash
node scripts/check-live.mjs https://l2gm.com
```

## 📝 Добавление данных

### Добавление нового сервера

Отредактируйте файл `data/servers.json`:

```json
{
  "id": 6,
  "name": "Название сервера",
  "url": "https://example.com",
  "chronicle": "Interlude",
  "rate": "x1",
  "startDate": "2026-01-30",
  "status": "premium",
  "badges": ["recommended"],
  "tags": ["Low рейты"]
}
```

### Добавление новой хроники

Отредактируйте файл `data/chronicles.json`:

```json
{
  "id": "new-chronicle",
  "name": "Новая хроника",
  "slug": "new-chronicle"
}
```

После добавления новой хроники автоматически создадутся страницы:
- `/chronicle/new-chronicle`
- `/chronicle/new-chronicle/rate/x1`
- `/chronicle/new-chronicle/rate/x3`
- ... (для всех рейтов)

### Добавление нового рейта

Отредактируйте файл `data/rates.json`:

```json
{
  "id": "x200",
  "name": "x200",
  "slug": "x200",
  "range": "x100-x1000"
}
```

После добавления автоматически создадутся страницы:
- `/rate/x200`
- `/chronicle/interlude/rate/x200`
- `/chronicle/c4/rate/x200`
- ... (для всех хроник)

## 🎨 Дизайн-система

Дизайн-система определена в `docs/design-system.json` и автоматически применяется через CSS переменные в `layouts/default.vue`.

Основные цвета:
- Фон: `#06080A` (main), `#0F1113` (surface)
- Основной: `#DF2027`
- Текст: `#F5F5F7` (primary), `rgba(245, 245, 247, 0.6)` (secondary)

Шрифт: **Onest** (Google Fonts)

## 🔍 SEO

Каждая страница автоматически получает:
- Уникальный `title`
- Уникальный `H1`
- Уникальный `description`
- Канонический URL
- SEO-текст внизу страницы

Все страницы рендерятся на сервере (SSR) для лучшей индексации.

## 📄 Структура страниц

### Главная страница (`/`)
- Список всех серверов в 2 колонки
- Категоризация по датам (Сегодня, Завтра, Вчера и т.д.)
- Панель фильтров справа
- SEO-текст

### Страницы хроник (`/chronicle/[chronicle]`)
- Фильтрованные серверы по хронике
- Уникальный SEO-контент

### Страницы рейтов (`/rate/[rate]`)
- Фильтрованные серверы по рейту
- Уникальный SEO-контент

### Комбинированные страницы (`/chronicle/[chronicle]/rate/[rate]`)
- Фильтрованные серверы по хронике и рейту
- Уникальный SEO-контент
